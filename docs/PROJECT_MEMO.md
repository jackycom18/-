# 任务看板项目备忘

## 项目介绍

Vue3 + Vite 纯前端任务看板，用于第十一届华为 ICT 大赛云赛道 1.1 实践赛题。

## 环境配置

- Node.js：v24.18.1
- 依赖安装：`npm install`
- 本地启动：`npm run dev`
- 访问地址：http://localhost:8085
- 测试：`npm test`
- 构建：`npm run build`

## 当前进展

- 已实现新增、删除、分类、星标、紧急标记、三列拖拽、主题切换和 localStorage 持久化。
- 21 项自动化测试通过，生产构建成功。
- 待完成：推送到个人 GitCode 仓库并发布到开发者作品展览馆。

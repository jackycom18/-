# 项目：像素大陆 2D 沙盒游戏

> 最后更新：2026-10-27

## 项目总览

- 目标：完成华为 ICT 1.3 练手题，交付一款可玩、可验证的 Terraria 风格 2D 侧视沙盒生存游戏。
- 技术栈：HTML5 Canvas、原生 JavaScript、Node.js 无头测试；零第三方依赖。
- 运行：在浏览器打开 `index.html`，或在本目录运行 `python -m http.server 8099`。
- 测试：`node --check game.js`、`node test-headless.js`。
- 入口：`index.html` 与 `game.js`。

# 码道泰拉瑞亚风格 2D 沙盒游戏设计

> 目标判据：华为 ICT 1.3 实验手册、用户“只使用免费资源”的约束和 `code-rules`。

## 目标

交付一款可双击运行的 Terraria 风格 2D 侧视沙盒生存游戏。项目使用 HTML5 Canvas 与原生 JavaScript，不依赖第三方运行时、图片或字体服务。

## 玩家体验

- A / D 左右移动，空格 / W 跳跃。
- 鼠标左键根据手持物执行挖掘、放置或攻击。
- 滚轮或数字键 1-0 切换十格快捷栏。
- E / Tab 打开背包与合成面板，H 查看操作帮助。
- 红心生命、金币、天数和快捷栏构成像素 HUD。

## 游戏系统

### 世界

每局使用随机种子生成起伏地表、树木、洞穴以及煤、铁、金三层矿脉。世界由二维图块数组表示，方块可挖掘、替换和放置。

### 物理

玩家和僵尸使用 AABB 与图块网格碰撞，先解算水平轴再解算垂直轴；实体可站立、坠落和跳跃越过障碍。

### 玩法

木、石、铁、金四档镐决定可挖掘的矿物等级；四档剑提供不同攻击力。木材、石材和矿物进入背包，工作台、火把及工具通过配方系统合成。高级配方需要玩家靠近工作台。

### 昼夜与战斗

白天和夜晚循环推进；天空颜色、太阳、月亮、星空和全局亮度随周期变化。火把和玩家自身产生局部光照。僵尸在夜间屏幕外生成、追踪并接触伤害，天亮后燃烧消失。击杀僵尸掉落金币。

### 渲染

采用 Canvas 像素块纹理、程序化角色、粒子、远近景山体、天空渐变和局部暗色遮罩。界面使用深褐边框、沙金标题、绿色行动按钮和泰拉瑞亚式红心 HUD，不加载外部视觉资源。

## 文件结构

- `index.html`：开始、死亡、背包/合成面板和 Canvas。
- `game.js`：世界生成、物理、战斗、合成、光照、渲染与主循环。
- `test-headless.js`：桩掉 DOM/Canvas 后模拟 600 秒，覆盖昼夜循环和僵尸生成。
- `README.md`：玩法、运行方式、验证命令和技术导览。
- `docs/PROJECT_MEMO.md`、`docs/CODE_MAP.md`：交接说明。

## 验证

- `node --check game.js`
- `node test-headless.js`，必须输出 `SMOKE OK: 600s 模拟无异常`
- 在其他浏览器页签用 Playwright 打开 `index.html`，确认开始界面、Canvas 和 HUD 正常渲染。
- 检查地表起伏、树木、洞穴、矿脉、合成可用性、火把光照、夜间僵尸和天亮计数。
